# AI 工具使用详情（Typst 详尽模板）

依据：

- 《全国大学生数学建模竞赛人工智能工具使用规定（2026 年试行）》
- 《2026 年五一数学建模竞赛人工智能工具使用规定》

模板版本：**2.0**（情景全清单，实填后目标约 **20–30 页**）。

## 提交要求摘要

| 赛道 | 论文内 | 详情载体 |
|------|--------|----------|
| **国赛** | 参考文献前「AI 工具使用声明」二选一 | 支撑包 PDF，文件名必须是 `AI 工具使用详情.pdf` |
| **五一** | 正文相应位置标注；参考文献列出 AI 工具 | 附录标题「AI工具使用详情」 |

详情至少包括：工具名与版本；目的与环节；提示与过程（可附示例）；采纳/修改/核验（润色除外亦建议记）。

红线：隐瞒、虚假声明、未审查 AI 当核心成果 → 取消评奖/竞赛资格。

## 文件

| 文件 | 说明 |
|------|------|
| `AI工具使用详情.typ` | 详尽可替换模板（双赛道 + A–K 情景全表 + Q1–Q5 + 8 条交互槽） |
| `AI工具使用详情.pdf` / `AI 工具使用详情.pdf` | 编译产物；国赛提交用带空格文件名 |

## 编译

```bash
cd docs/ai-use   # 或 templates/cumcm/support
typst compile "AI工具使用详情.typ" "AI工具使用详情.pdf"
cp "AI工具使用详情.pdf" "AI 工具使用详情.pdf"
```

把全部红色【填写】换成实事；**未发生的情景整行删除**。空模板编译约十余至二十余页；实填交互与分问后冲到 20–30 页很正常。不必为凑页而灌水。
